# Self-hosted fonts

Original, unmodified variable TrueType fonts from the [Google Fonts repository](https://github.com/google/fonts). Each font is distributed with its original SIL Open Font License.

| Asset | Original source | Used weights |
|---|---|---|
| `geist-mono.ttf` | [Geist Mono](https://github.com/google/fonts/tree/main/ofl/geistmono) | 400–500 |
| `hanken-grotesk.ttf` | [Hanken Grotesk](https://github.com/google/fonts/tree/main/ofl/hankengrotesk) | 400–600 |
| `roboto-mono.ttf` | [Roboto Mono](https://github.com/google/fonts/tree/main/ofl/robotomono) | 300–700 |

The complete upstream fonts retain their available character sets. The CSS uses `font-display: swap` and same-origin URLs; the visitor does not contact Google Fonts. Keep each `*-OFL.txt` alongside the corresponding font when redistributing or updating these files.
